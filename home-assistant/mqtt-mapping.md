## switch (4)

metric, so the control shows what the car is actually doing.

| Name | state metric | on | off |
|---|---|---|---|
| Charge to 100% once | `xva.v.c.limit.override` | `xva chargelimit override` | `xva chargelimit resume` |
| Charging | `v.c.charging` | `charge start` | `charge stop` |
| Climate | `v.e.hvac` | `climatecontrol on` | `climatecontrol off` |
| Windows | `xva.v.e.windows` | `xva windows down` | `xva windows up` |
